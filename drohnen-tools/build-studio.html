Übersicht

Schub/Gewicht und Flugzeit sind grobe Schätzungen aus den eingetragenen Werten (Herstellerangaben zum Schub, typischer Wirkungsgrad je Prop-Größe).

Kompatibilität

    Speichern & Export

    Das Build-Paket enthält Teileliste, Schaltplan (SVG) und Betaflight-Befehle. Der Stand bleibt zusätzlich in diesem Browser gespeichert.

    Bauteil einfügen

    Bauteil auf die Fläche ziehen oder anklicken. Kabel: auf ein Pad klicken, dann auf das Ziel-Pad.

    Ziehen = verschieben · Mausrad = Zoom · Entf = löschen · Esc = Kabel abbrechen

      Betaflight-CLI

      Aus der UART-Belegung erzeugt. Im Betaflight Configurator im Tab CLI einfügen – vorher prüfen, ob die Pads auf deinem FC wirklich so heißen.
