02 / So geht's

Drei Abläufe, ein Ziel: fliegen.

Die Sender-Werkzeuge schreiben auf die SD-Karte, die Drohnen-Werkzeuge sprechen per USB mit Flugcontroller und Reglern, der Blackbox Viewer wertet nach dem Flug die Logs aus.

A / Sender

Vom Entwurf auf den Sender

Gestalten

Im Theme Studio Farben wählen, im Lua Studio Elemente und Bilder platzieren. Die Vorschau zeigt sofort, wie es am Sender aussieht.

Sichern

Vorher im Backup Studio die Karte sichern. Entwürfe speicherst du im Bollisoft-Konto oder als ZIP.

Auf die Karte

Sender per USB verbinden, USB Storage (SD) wählen und direkt aus dem Studio schreiben. Ohne Chrome/Edge das ZIP ins Hauptverzeichnis entpacken.

Am Sender wählen

Neu starten. Themes unter SYS → Themes, Widgets über „Hauptansichten einrichten“, Tools unter SYS → Tools.

B / Drohne

Einrichten und aktualisieren

Verbinden

Flugcontroller per USB anschließen. Chrome oder Edge fragen einmal nach dem Zugriff auf die serielle Schnittstelle.

Sichern

Vor jedem Update im Betaflight Configurator unter CLI diff all ausgeben und als Datei speichern.

Einrichten

Ports, Empfänger, Modi und PIDs in Betaflight, Regler per Passthrough im ESC Configurator, ELRS mit Binding-Phrase und Region.

Aktualisieren

Firmware für Flugcontroller, Regler und ELRS flashen, danach die gesicherten Einstellungen zurückspielen.

C / Nach dem Flug

Auswerten und vergleichen

Log holen

Blackbox-Log (.bbl, .bfl) von der Karte des Flugcontrollers kopieren oder den Flash direkt per USB auslesen.

Video dazu

Optional das Flugvideo laden. Der Viewer synchronisiert es über Tonspur, Gas-Stoß oder Arm-Piepser.

Auswerten

Tricks, Punkte und Combos erscheinen in der Timeline, das HUD zeigt Lage und Gas passend zum Video.

Vergleichen

Mit Bollisoft-Konto reichst du deinen Score im Leaderboard ein. Demo-Flüge zählen nicht.

03 / SD-Karte

Wo welche Datei hingehört.

EdgeTX sucht Themes, Skripte, Bilder und Sounds in festen Ordnern. Theme Studio, Lua Studio und Backup Studio legen alles an die richtige Stelle – direkt auf die Karte oder im ZIP.

SD-Karte/
├─ RADIO/               ← Sender-Einstellungen · Backup Studio
├─ MODELS/              ← Modelle · Backup Studio
├─ THEMES/
│  └─ MeinTheme/        ← Theme Studio
│     ├─ theme.yml
│     ├─ logo.png · background.png
│     └─ screenshot1.png …
├─ WIDGETS/
│  └─ FLUGDAT/          ← Widget · Lua Studio
│     ├─ main.lua
│     └─ logo.png         ← Bilder aus „Dateien“
├─ SCRIPTS/
│  ├─ TOOLS/Flugbuch.lua   ← Tool
│  ├─ FUNCTIONS/akku.lua  ← Funktion
│  └─ MIXES/limit.lua      ← Mischer
└─ SOUNDS/de/           ← eigene Sounds

Kurze Namen

Funktions- und Mischer-Skripte dürfen höchstens 6 Zeichen haben, Widget-Ordner höchstens 8. Die Studios kürzen das automatisch.

Neu starten

Neue Widgets und Themes erkennt EdgeTX erst nach einem Neustart. Die Karte vorher am PC auswerfen.

Vorher sichern

Im Backup Studio sicherst du die Karte als ZIP oder im Bollisoft-Konto. Vor jedem Zurückspielen legt es automatisch eine Sicherung an.

Firmware nicht auf die Karte

Die TX15-Firmware (.uf2) installiert das Backup Studio in Schritt 05 über den Bootloader direkt auf das Laufwerk EDGETX_UF2 – nicht über die SD-Karte.
