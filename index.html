02 / Ablauf

Vom Entwurf auf den Sender.

Der Weg ist bei Themes und Skripten derselbe. Nur der Zielordner auf der Karte ist ein anderer.

Gestalten

Im Studio Farben wählen oder Elemente platzieren. Die Vorschau zeigt sofort, wie es am Sender aussieht.

Exportieren

ZIP herunterladen. Darin liegen schon die richtigen Ordner, etwa THEMES/ oder WIDGETS/.

Auf die Karte

SD-Karte oder Sender per USB verbinden und das ZIP ins Hauptverzeichnis entpacken.

Am Sender wählen

Theme unter SYS → Themes aktivieren, Widgets über „Hauptansichten einrichten“ platzieren.

03 / SD-Karte

Wo welche Datei hingehört.

EdgeTX sucht Themes und Skripte in festen Ordnern. Die Studios legen alles an die richtige Stelle.

SD-Karte/
├─ THEMES/
│  └─ MeinTheme/        ← Theme Studio
│     ├─ theme.yml
│     └─ screenshot1.png …
├─ WIDGETS/
│  └─ FLUGDAT/main.lua  ← Widget
└─ SCRIPTS/
   ├─ TOOLS/Flugbuch.lua  ← Tool
   ├─ FUNCTIONS/akku.lua ← Funktion
   └─ MIXES/limit.lua     ← Mischer

Kurze Namen

Funktions- und Mischer-Skripte dürfen höchstens 6 Zeichen haben, Widget-Ordner höchstens 8. Die Studios kürzen das automatisch.

Neustart nach dem Kopieren

Neue Widgets und Themes erkennt EdgeTX erst nach einem Neustart des Senders.

Vorher sichern

Erstelle im Backup Studio ein Backup, bevor du Dateien ersetzt oder die Firmware aktualisierst. Ein misslungenes Skript ist dann schnell rückgängig gemacht.
